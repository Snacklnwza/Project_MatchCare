# สถานะงาน MatchCare

อัปเดต 29 กันยายน 2569 หลังผู้ใช้ยืนยันว่าทดสอบขั้นแจ้งจบและผู้ว่าจ้างยืนยันบน Vercel ผ่าน

## งานที่ทำแล้วและทดสอบผ่าน

| งาน | สถานะและหลักฐาน |
| --- | --- |
| ผู้ดูแลบันทึกโปรไฟล์ ทักษะ และเปิดพร้อมรับงาน | ผู้ใช้ทดสอบหน้าเว็บผ่าน |
| ส่งเอกสารผ่าน Storage ส่วนตัว | ผู้ใช้ทดสอบหน้าเว็บผ่าน และทดสอบอัปโหลดไฟล์จริงผ่าน API แล้ว |
| แอดมินเปิดเอกสารและอนุมัติผู้ดูแล | ผู้ใช้ทดสอบหน้าเว็บผ่าน และทดสอบสิทธิ์ผ่าน API/SQL แล้ว |
| ผู้ว่าจ้างสร้างประกาศและค้นผู้ดูแลเรียงตามทักษะที่ตรงกัน | ผู้ใช้ทดสอบหน้าเว็บผ่าน และ SQL ตรวจเงื่อนไขค้นหาผ่าน |
| ส่งคำเชิญและผู้ดูแลตอบรับ | ผู้ใช้ทดสอบหน้าเว็บผ่าน และตรวจการเชิญซ้ำ/ตอบรับแทนคนอื่นในชุดทดสอบแล้ว |
| แสดงว่าจับคู่สำเร็จและเปิดข้อมูลติดต่อให้ทั้งสองฝ่าย | ผู้ใช้ทดสอบหน้าเว็บผ่าน และ API ปฏิเสธการอ่านก่อนตอบรับได้ถูกต้อง |
| ผู้ว่าจ้างเริ่มงานหลังจับคู่ | API จริงผ่าน: เริ่มได้หนึ่งครั้ง, admin เริ่มแทนไม่ได้, เริ่มซ้ำถูกปฏิเสธ และผู้ดูแลเห็นสถานะใหม่; lint/build และ SQL regression ผ่าน |
| ผู้ดูแลแจ้งจบและผู้ว่าจ้างยืนยัน | API จริงผ่าน: เก็บเวลาขอจบ/เวลายืนยัน, ทั้งคู่เห็นสถานะเสร็จ, role ผิดและกดซ้ำถูกปฏิเสธ; งานรอยืนยันปิดผู้ป่วยไม่ได้; lint/build และ SQL regression ผ่าน |
| ผู้ดูแลแจ้งจบและผู้ว่าจ้างยืนยันบน Vercel | ผู้ใช้ยืนยันว่าทดสอบผ่าน |
| จัดโครงสร้างไฟล์และคู่มือโค้ด | แยก pages, components, styles, lib, hooks พร้อมคู่มือใน code-guide |

รายการนี้ยืนยันเฉพาะเส้นทางที่ผู้ว่าจ้างเริ่มส่งคำเชิญ ยังไม่ถือว่าการสมัครงานเองของผู้ดูแลหรือ backlog ทุกข้อเสร็จแล้ว หมายเลข backlog ในคู่มือเป็นการอ้างอิงเดิม ยังไม่ได้ปรับสถานะใน Google Sheets จากรอบนี้

## งานต่อไปตามลำดับ

1. ทดสอบผู้ดูแลสองคนตอบรับงานเดียวกันพร้อมกัน ต้องมีผู้ตอบรับสำเร็จได้เพียงคนเดียว
2. ทดสอบประวัติการจ้างตามสถานะงานจริง
3. พัฒนาการสมัครงานที่ผู้ดูแลเริ่มเอง
4. ทดสอบ flow ครบอีกครั้งบน Vercel หลังรวม PR

## งานที่ยังเหลือ

- ผู้ดูแลค้นประกาศและส่งใบสมัครเอง
- ถอนคำเชิญหรือยกเลิกคู่ที่ตอบรับแล้ว
- ประวัติการจ้างฉบับสมบูรณ์
- รีวิวและการแจ้งเตือน
- ตรวจเวลางานทับซ้อนและจัดการไฟล์ที่อัปโหลดสำเร็จแต่ลงทะเบียนเอกสารไม่สำเร็จ

กำหนดส่งที่ผู้ใช้แจ้งคือ 12 ตุลาคม 2569 จัดลำดับงานที่จำเป็นต่อการสาธิตให้เสร็จก่อนช่วงสอบ 4–9 ตุลาคม ยังไม่ได้ยืนยันตารางรายวันใหม่หรือเปลี่ยนขอบเขตงานที่ต้องส่ง
