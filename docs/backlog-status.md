# สถานะงาน MatchCare

อัปเดต 3 ตุลาคม 2569 เทียบโค้ดและผลทดสอบกับ backlog Sprint 2 ใน Google Sheets แล้ว สถานะ ID 5–13 ในชีตเป็น “ผ่านทดสอบหลัก” หมายถึงฟังก์ชันหลักมีแล้วและชุดทดสอบที่ระบุด้านล่างผ่าน ยังไม่ใช่การปิด Definition of Done

| ID | งาน | สถานะตามหลักฐานล่าสุด |
| --- | --- | --- |
| 5 | โปรไฟล์และทักษะผู้ดูแล | ฟังก์ชันและการบันทึกทำงานแล้ว; ยังต้องเช็กตาม Acceptance Criteria บน Vercel |
| 6 | ผู้ดูแลค้นหางาน | หน้า ตัวกรอง และ SQL test ผ่าน |
| 7 | ผู้ดูแลส่งเอกสาร | ส่งไฟล์ส่วนตัวและทดสอบสิทธิ์แล้ว; ยังต้องเช็กตาม Acceptance Criteria บน Vercel |
| 8 | แอดมินจัดคลังแท็ก | โค้ดและ SQL test ผ่าน, migration ติดตั้งบนฐานจริง และรวมเข้า main แล้ว; ยังต้องเช็กหน้าจอ |
| 9 | ผู้ว่าจ้างค้นหาผู้ดูแล | โค้ด ตัวกรอง SQL test และ browser mock ผ่าน รวมเข้า main แล้ว; ยังต้องทดสอบบน Vercel |
| 10 | ส่งคำเชิญ/ใบสมัคร | เส้นทางหลักทั้งสองแบบทำงานและมี SQL test; รอเช็กบน Vercel |
| 11 | ตอบรับ/ปฏิเสธ | ทดสอบสิทธิ์และตอบรับพร้อมกันสอง connection ผ่าน รวม PR #17 เข้า main แล้ว; ยังต้องเช็ก UI สองบัญชี |
| 12 | เปิดข้อมูลติดต่อหลังจับคู่ | API จำกัดคู่สัญญาและมี UI แสดงแล้ว; รอเช็กทั้งสองบัญชีบน Vercel |
| 13 | สลับความพร้อม | ทำงานและผูกกับผลค้นหา/คำเชิญแล้ว; ยังต้องเช็กตาม Acceptance Criteria บน Vercel |

**อัปเดต 10 ตุลาคม:** ผู้ใช้ยืนยันว่าได้ตรวจงาน Sprint 2 เรียบร้อยแล้ว ข้อความรอตรวจในตารางข้างต้นเป็นบันทึกวันที่ 3 ตุลาคม ไม่ใช่งานที่สั่งให้ทดสอบซ้ำในรอบนี้ PR #17 และ #18 รวมเข้า main แล้ว ชุดทดสอบฐานข้อมูล lint และ build ผ่าน เดินหน้าทำ Sprint 3 ต่อ

ID 16 เพิ่มหน้าประวัติงานและ API แล้ว ทดสอบฐานข้อมูลในเครื่องและ Supabase จริงผ่าน ดูรายละเอียดที่ [คู่มือประวัติงาน](code-guide/12-job-history.md)

ID 15 เพิ่มให้ดาวและรีวิวจากงานที่จบแล้ว พร้อมคะแนนเฉลี่ยในข้อมูลผู้ดูแล ทดสอบฐานข้อมูลจริงและ UI สมมติผ่าน ดูรายละเอียดที่ [คู่มือรีวิว](code-guide/13-job-reviews.md) ทั้งสองฟังก์ชันติดตั้ง backend แล้ว ส่วน frontend ยังรอรวมสาขาและ deploy

Sprint 3 ที่ยังเหลือ: ID 17 แจ้งเตือน, ID 18 คะแนนที่รวมสภาวะผู้ป่วย และ ID 19 สถิติแอดมิน

งาน Sprint 3 เช่นรีวิวและประวัติการจ้างฉบับสมบูรณ์ ไม่รวมอยู่ในตารางนี้ กำหนดส่งโครงงานที่ผู้ใช้แจ้งคือ 12 ตุลาคม 2569 โดยตั้งเป้าให้งานทั้งหมดเสร็จ 4 ตุลาคมก่อนช่วงสอบ
