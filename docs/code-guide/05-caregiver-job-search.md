# ผู้ดูแลค้นหาประกาศงาน (ID 6)

## เริ่มจากหน้าไหน

ผู้ดูแลกดเมนู **ค้นหางาน** ใน `Navbar.jsx` แล้ว `RoleDashboard.jsx` แสดง `JobSearch.jsx` หน้านี้มีตัวกรองจังหวัด อำเภอ/เขต วันที่ ทักษะ และช่วงค่าตอบแทน กด **ค้นหา** เพื่อใช้ตัวกรอง หรือกด **ล้างตัวกรอง** เพื่อกลับไปดูงานทั้งหมด รายการงานแบ่งครั้งละ 20 รายการ

## ข้อมูลเดินทางอย่างไร

1. `JobSearch.jsx` เก็บค่าตัวกรองใน React state และส่งให้ `searchOpenJobs()` ใน `frontend/src/lib/openJobs.js`
2. `searchOpenJobs()` เรียก RPC `public.search_open_jobs` พร้อมตัวกรองและตำแหน่งหน้า ฐานข้อมูลกรองก่อนแบ่งหน้า จึงไม่พลาดงานที่อยู่นอก 50 รายการแรก
3. RPC ชั้นใน `match_internal.search_open_jobs` ตรวจว่าผู้เรียกเป็นผู้ดูแล แล้วอ่านเฉพาะประกาศ `open` และคอลัมน์ที่จำเป็นสำหรับการตัดสินใจ ไม่ส่งรหัสผู้ป่วย ที่อยู่ละเอียด หรือเบอร์ติดต่อ
4. เมื่อกด **ดูรายละเอียด** หน้าเว็บเรียก `public.get_open_job_details` อีกครั้ง หากประกาศปิดไประหว่างนั้น ฟังก์ชันคืน `null` และหน้าเว็บแจ้งให้โหลดรายการใหม่

SQL ฉบับสำหรับสร้างฐานใหม่อยู่ท้าย `database/schema/06_matching.sql` ส่วนฐาน Supabase ที่ใช้งานอยู่ติดตั้งฟังก์ชันทั้งสองแล้ว คำสั่ง `list_open_jobs()` ที่สร้างผ่าน SQL Editor ช่วงเริ่มงานยังอยู่ แต่หน้าเว็บใช้ `search_open_jobs()` แทน

## ทำไมแยก RPC เป็นสองชั้น

`job_posts` มี RLS ให้ผู้ว่าจ้างอ่านประกาศของตัวเองเท่านั้น การให้ผู้ดูแลอ่านตารางนี้ทั้งแถวจะเปิดที่อยู่ละเอียด จึงใช้ฟังก์ชันชั้นในใน schema `match_internal` ที่ไม่เปิดผ่าน Data API ฟังก์ชันนี้ตรวจบทบาทจาก `auth.uid()` ก่อนอ่านข้อมูลข้าม RLS และเลือกคอลัมน์ที่ส่งออกอย่างชัดเจน ชั้น `public` เป็นจุดเรียกของหน้าเว็บและให้สิทธิ์เฉพาะผู้ที่เข้าสู่ระบบ

วันที่กรองตามวันในเขตเวลา `Asia/Bangkok` และนับงานที่ช่วงเวลาทับกับวันนั้น ค่าตอบแทนต่ำสุดและสูงสุดใช้ได้เมื่อเลือกหน่วยก่อน เพื่อไม่เปรียบเทียบเงินต่อชั่วโมงกับเงินต่อเดือน

## ตรวจงาน

- `npm --prefix database test` ตรวจบทบาท ตัวกรอง การแบ่งหน้า รายละเอียด งานปิด และคอลัมน์ข้อมูลส่วนตัวด้วยข้อมูลสมมติที่ rollback
- `npm --prefix frontend run lint` ตรวจโค้ดหน้าเว็บ
- `node frontend/node_modules/vite/bin/vite.js build --configLoader native` สร้างเว็บจริงในสภาพแวดล้อมที่ Vite แบบปกติติด `spawn EPERM`
- ทดสอบบน localhost ด้วยบัญชีผู้ดูแล: รายการเปิดรับ รายละเอียด จังหวัด วันที่ ทักษะ ค่าตอบแทน และล้างตัวกรอง

การรับสมัครงานยังเป็น ID 10 และไม่ได้เปิดจากหน้านี้ในขั้น ID 6
