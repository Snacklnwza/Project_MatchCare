# คลังกลางทักษะและรอยโรค (ID 8)

แอดมินเปิดเมนู **คลังกลาง** เลือกทักษะหรือรอยโรค แล้วเพิ่มหรือแก้ไขชื่อและคำอธิบายได้ รายการใหม่เปิดใช้งานทันที กดปิดใช้งานต้องยืนยันก่อน และเปิดกลับได้

## โค้ดแต่ละส่วน

- `frontend/src/pages/AdminCatalog.jsx` แสดงฟอร์ม รายการ ตัวกรองชื่อ/สถานะ และผลบันทึก แยกตัวแก้ไขด้วย key ตามชนิดเพื่อไม่ปนข้อมูลระหว่างสองคลัง
- `frontend/src/lib/catalog.js` ตรวจชนิดคลังก่อนเรียก Supabase และแปลข้อผิดพลาดชื่อซ้ำ ไม่มีสิทธิ์ หรือบันทึกล้มเหลวเป็นภาษาไทย
- `frontend/src/styles/Catalog.css` จัดฟอร์มกับรายการเป็นสองคอลัมน์บนจอใหญ่และหนึ่งคอลัมน์บนมือถือ
- `database/schema/09_catalog.sql` ให้เพิ่มและแก้ไขผ่าน RLS เฉพาะบัญชีที่มี role admin ใน profiles ใช้สิทธิ์ระดับคอลัมน์และไม่ให้ DELETE
- `private.normalize_catalog_item()` ตัดช่องว่างหัวท้าย ตรวจชื่อ 1–120 ตัวอักษร และคำอธิบายไม่เกิน 1,000 ตัวอักษร Unique index ป้องกันชื่อซ้ำหลังตัดช่องว่างและไม่แยกตัวพิมพ์

## ทำไมปิดใช้งานแทนลบ

การลบแท็กที่ใช้อยู่จะกระทบประวัติผู้ป่วย โปรไฟล์ และประกาศ จึงเก็บแถวเดิมแล้วเปลี่ยน `is_active` ผู้เข้าสู่ระบบอ่านชื่อคลังเก่าได้ แต่ฟอร์มเพิ่มใหม่แสดงเฉพาะรายการที่เปิดใช้งาน ฟอร์มแก้ไขแสดงแท็กเก่าที่เลือกไว้เป็นรายการอ่านอย่างเดียว และบันทึกข้อมูลส่วนอื่นได้โดยไม่ลบความสัมพันธ์เดิม

ปรับ `save_patient_with_tags` และ `update_job_with_tags` ให้ข้ามการ insert ความสัมพันธ์ที่มีอยู่แล้ว เพื่อไม่ให้ RLS ปฏิเสธแท็กเก่าที่ปิดไปแล้ว ส่วนการเพิ่มความสัมพันธ์ใหม่ยังตรวจว่ารายการเปิดใช้งานอยู่

## ผลทดสอบ 2 ตุลาคม 2569

- `catalog_test.sql` ผ่านทั้งในเครื่องและ Supabase จริงแบบ rollback: เพิ่ม/แก้ไข/ปิด/เปิด, ชื่อว่างและซ้ำ, สิทธิ์ admin/employer/caregiver/anon, ห้าม hard delete และอ่าน/บันทึกประวัติแท็กที่ถูกปิด
