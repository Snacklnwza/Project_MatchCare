## สถานะจริง

- ฟังก์ชันค้นหา schema 06 ติดตั้งบน Supabase แล้วจากรอบก่อน
- schema 07–08 ติดตั้งบน Supabase จริงแล้วด้วย migration `20260928084433_caregiver_documents_and_invitations`
- PostgreSQL ในเครื่องผ่าน schema 01–08, matching_search_test, workflow_integration_test และ sprint1_integration_test
- UI ใช้ข้อมูลสมมติทดสอบส่งเอกสาร อนุมัติ/ปฏิเสธ ตอบรับคำเชิญ และดูข้อมูลติดต่อผ่านแล้ว
- build ผ่าน; lint ผ่าน
- ทดสอบ SQL แบบ rollback บน Supabase จริงผ่านแล้ว
- ทดสอบผ่าน Supabase JS ด้วย session จริงของบัญชีทดสอบทั้งสาม role ผ่าน: ส่งไฟล์ PNG → ลงทะเบียนเอกสาร → แอดมินดาวน์โหลด/อนุมัติ → ค้นผู้ดูแลตามทักษะ → เชิญ → ตอบรับ → เปิดข้อมูลติดต่อ
- ทดสอบสิทธิ์จริงผ่าน: ผู้ว่าจ้าง/ผู้ไม่ล็อกอินอ่านไฟล์ไม่ได้, ผู้ดูแลอนุมัติตนเองไม่ได้, เชิญซ้ำไม่ได้ และอ่านข้อมูลติดต่อก่อนตอบรับไม่ได้
- ทดสอบตอบรับใบสมัครสองใบของงานเดียวกันพร้อมกันจากสอง connection ผ่านแล้ว: รับได้หนึ่งคน อีก connection รอ lock แล้วถูกปฏิเสธ ดูหลักฐานใน [คู่มือพิจารณาใบสมัคร](07-employer-reviews-applications.md) ส่วน UI ทั้ง flow บน Vercel ยังรอทดสอบ
- ผู้ใช้ยืนยันว่าทดสอบผ่านหน้าเว็บครบทั้ง 5 ขั้นแล้ว: โปรไฟล์/เอกสาร → แอดมินอนุมัติ → ผู้ว่าจ้างค้นหาและเชิญ → ผู้ดูแลตอบรับ → ทั้งสองฝ่ายดูข้อมูลติดต่อ โดยยังไม่ได้ระบุว่าใช้ localhost หรือ Vercel
- ผู้ว่าจ้างเริ่มงานที่จับคู่แล้วได้ผ่าน RPC; role อื่นเริ่มแทนไม่ได้, เริ่มซ้ำไม่ได้ และผู้ดูแลเห็นสถานะดำเนินงานผ่าน API จริง
- ผู้ดูแลแจ้งจบงานและผู้ว่าจ้างยืนยันได้ตามลำดับ สถานะ/เวลาจบแสดงกับทั้งคู่; ทดสอบ role ผิดและการทำซ้ำแล้ว
- งานรอการยืนยันจบยังล็อกผู้ป่วยไม่ให้ถูกปิดใช้งาน
- `npm run lint`, `npm run build` และ SQL regression ผ่านหลังเพิ่มปุ่มเริ่มงานและแสดงสถานะในหน้าคำเชิญ
- สถานะงานและสิ่งที่ต้องทำต่ออยู่ใน [รายการงานล่าสุด](../backlog-status.md)

## ชุดติดตั้งที่ใช้แล้ว

`supabase/migrations/20260928084433_caregiver_documents_and_invitations.sql`

ประกอบด้วย schema 07–08 ใน transaction เดียว: ตาราง/สิทธิ์เอกสาร, bucket ส่วนตัว, RPC ตรวจเอกสาร, ตารางคำเชิญ, RPC จับคู่ และ trigger ประกาศงาน ไม่มีการลบข้อมูลเดิมหรือเปลี่ยนบทบาทบัญชีจริง

วันที่ 28 กันยายน 2026 ติดตั้งและทดสอบตามการอนุมัติของผู้ใช้แล้ว ไม่ต้องรันไฟล์ซ้ำบนโปรเจกต์นี้ อ่านรายละเอียดที่ [ผลทดสอบฐานจริง](04-live-test-results.md)
