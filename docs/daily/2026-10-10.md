# บันทึกงาน 10 ตุลาคม 2569

ผู้ใช้ยืนยันว่าได้ตรวจงาน Sprint 2 แล้ว จึงเดินหน้าทำ Sprint 3 โดยเริ่มประวัติงานก่อน เพื่อใช้เป็นทางเข้ารีวิวงานที่เสร็จแล้ว คอมมิตเขียนสั้น ๆ บอกสิ่งที่ทำตามที่ผู้ใช้ขอ

## ประวัติงาน (ID 16)

- รวมงานที่จับคู่จากคำเชิญและใบสมัครให้ทั้งสองฝ่ายดูย้อนหลัง กรองกำลังทำ/เสร็จ/ยกเลิก และแบ่งหน้าละ 20 งาน
- เพิ่ม RPC รายการและรายละเอียด ตรวจคู่สัญญาที่ฐานข้อมูล ไม่คืนข้อมูลผู้ป่วยและข้อมูลติดต่อในรายการ
- เพิ่มทางเข้าในเมนูบัญชี ปรับการแสดงรายละเอียดบนมือถือ และแก้ footer ที่ทำให้หน้าล้นด้านข้าง
- ติดตั้ง `job_history` บน Supabase แล้ว ชุด SQL ใหม่ผ่านทั้งในเครื่องและฐานจริงแบบ rollback ชุดเดิมกับ lint ผ่าน
- คู่มืออยู่ที่ [ประวัติงาน](../code-guide/12-job-history.md)

## รีวิวผู้ดูแล (ID 15)

- ผู้ว่าจ้างให้ดาว 1–5 และเขียนรีวิวจากงานที่ยืนยันจบแล้วได้ครั้งเดียว ผู้ดูแลเปิดอ่านจากประวัติงาน
- เพิ่มคะแนนเฉลี่ยกับรีวิวล่าสุดในหน้าค้นหา รายการแนะนำสำหรับประกาศ และโปรไฟล์ผู้ดูแล
- ตรวจสิทธิ์ที่ฐานข้อมูล ไม่รับรหัสผู้เขียน/ผู้รับรีวิวจากหน้าเว็บ และไม่ส่งรหัสงานหรือข้อมูลผู้ป่วยในรีวิวที่แสดงกับผู้ใช้อื่น
- ติดตั้ง `job_reviews` บน Supabase แล้ว ทดสอบ SQL จริงแบบ rollback รวมการเขียนซ้ำ บทบาทผิด งานไม่จบ และข้อมูลที่ API คืน
- ทดสอบฟอร์มจริงกับ API สมมติ: เลือกดาว บันทึกผิดพลาด ข้อมูลไม่หาย กดซ้ำ อ่านหลังบันทึก ผู้ดูแลอ่านอย่างเดียว และมือถือ
- ชุดอัปเกรดจาก main, lint และ production build ผ่าน Security Advisor ไม่มีคำเตือนใหม่ เหลือ Auth leaked password protection เดิม
- คู่มืออยู่ที่ [รีวิวหลังจบงาน](../code-guide/13-job-reviews.md)
- คอมมิตประวัติ `a198b86` — เพิ่มหน้าประวัติงานให้ทั้งสองฝ่าย
