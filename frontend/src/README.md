# โครงสร้างโค้ดหน้าเว็บ

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `pages/` | หน้าหลักของแต่ละบทบาทและหน้าที่เลือกจากเมนู |
| `components/` | ส่วนประกอบหน้าจอและฟอร์ม เช่น Navbar, JobForm |
| `styles/` | CSS ทั้งหมด: index.css ตั้งค่าพื้นฐาน, App.css สไตล์ร่วม, CaregiverDashboard.css หน้าหลักผู้ดูแล |
| `assets/` | รูปและ SVG แยกตามส่วนที่ใช้งาน |
| `lib/` | Supabase client และฟังก์ชันช่วยจัดการข้อมูล |
| `hooks/` | พฤติกรรม React ที่ใช้ซ้ำ เช่น โหลดรายการและลองใหม่ |
| `data/` | ข้อมูลพื้นที่และเอกสารสิทธิ์ของแหล่งข้อมูล |
| `App.jsx` | จัดการ session และเลือกหน้าก่อนหรือหลังเข้าสู่ระบบ |
| `main.jsx` | เริ่มแอปและโหลด CSS พื้นฐาน |

## แนวทางแก้โค้ด

- JSX อยู่ใน pages หรือ components; CSS อยู่ใน styles และ import จากไฟล์ที่ใช้งาน
- ภาพประกอบ SVG ขนาดใหญ่เก็บเป็นไฟล์ใน assets; ไอคอนสั้นที่ใช้ currentColor เก็บใน JSX ได้
- แยกสถานะ loading/error/success ให้เห็นชัด แทนการซ้อนเงื่อนไขหลายชั้น
- ตั้งชื่อฟังก์ชันให้สื่อการกระทำ เช่น openProfile และไม่สร้าง abstraction สำหรับโค้ดสั้นที่ใช้เพียงจุดเดียว
- เมื่อย้ายไฟล์ ตรวจ import แล้วรัน `npm run lint` และ `npm run build` ใน frontend
